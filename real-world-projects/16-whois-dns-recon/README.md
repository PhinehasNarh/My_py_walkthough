# 16. WHOIS & DNS Recon Tool

## Problem
Gather public registration and DNS information about a domain for recon.

## What you will build
- Look up WHOIS registration details.
- Resolve A, MX, NS, and TXT records.
- Attempt a zone transfer and report if it is allowed.
- Enumerate subdomains from a wordlist.

## Concepts practiced
- DNS
- WHOIS
- Recon basics

## Libraries
- dnspython
- python-whois

## Stretch goals
- Add concurrency for subdomain enumeration.
- Export findings to JSON.
