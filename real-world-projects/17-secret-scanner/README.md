# 17. Secret / API-Key Scanner

## Problem
Catch API keys and secrets accidentally left in your code.

## What you will build
- Walk a code folder.
- Match content against regex patterns for common secrets.
- Reduce false positives with entropy checks.
- Report file, line, and the kind of secret.

## Concepts practiced
- Regular expressions
- Entropy
- Static scanning

## Libraries
- re
- math

## Stretch goals
- Scan git history, not just the working tree.
- Add an ignore file for known false positives.
