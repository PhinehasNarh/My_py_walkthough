# 20. OSINT Username Hunter

## Problem
Check whether a username exists across many sites during an OSINT investigation.

## What you will build
- Keep a list of sites and their profile URL patterns.
- Request each site's profile URL for the username.
- Decide present or absent from the response.
- Report where the username was found.

## Concepts practiced
- HTTP requests
- Concurrency
- OSINT

## Libraries
- requests
- concurrent.futures

## Stretch goals
- Add more sites from a JSON config.
- Export a clean report with links.
