# 34. Invoice / Receipt PDF Generator

## Problem
Generate clean, consistent invoices from data instead of editing documents by hand.

## What you will build
- Read client and line-item data.
- Compute subtotals, tax, and total.
- Render a styled PDF invoice.
- Number and save each invoice.

## Concepts practiced
- Templating
- PDF generation
- Calculations

## Libraries
- reportlab
- (or fpdf2)

## Stretch goals
- Mail-merge a batch from a CSV.
- Email each invoice to its client.
