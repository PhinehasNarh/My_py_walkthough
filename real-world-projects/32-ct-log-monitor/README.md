# 32. Certificate Transparency Monitor

## Problem
Detect rogue or unexpected certificates issued for your domain.

## What you will build
- Query certificate transparency logs for a domain.
- Collect all certificates and their issuers.
- Compare against the certificates you expect.
- Flag anything new or unexpected.

## Concepts practiced
- Certificate transparency
- APIs
- Change detection

## Libraries

## Stretch goals

- Track subdomains discovered via CT.
