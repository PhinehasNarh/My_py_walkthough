# 29. ETL Pipeline

## Problem
Pull data from an API, clean it, store it, and report on a schedule.

## What you will build
- Extract records from an API.
- Transform and validate the fields.
- Load them into SQLite.
- Generate a scheduled summary report.

- Scheduling
- Data validation

## Libraries

- sqlite3
- schedule
