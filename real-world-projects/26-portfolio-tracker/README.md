# 26. Stock / Crypto Portfolio Tracker

## Problem
Track your holdings' value and get alerted on big moves.

## What you will build
- Store holdings (symbol, quantity, buy price).
- Fetch current prices from a free API.
- Compute profit and loss per holding and overall.
- Alert when a holding moves past a threshold.

## Concepts practiced
- APIs
- Calculations
- Alerts

## Libraries
- requests

## Stretch goals
- Log value over time and chart it.
- Add target prices and notifications.
