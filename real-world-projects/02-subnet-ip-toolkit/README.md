# 02. Subnet & IP Toolkit

## Problem
Do the IP and subnet maths you constantly need in networking, from one tool.

## What you will build
- Take a network in CIDR form.
- Print network address, broadcast, usable host range, and host count.
- Detect which subnet a given address belongs to.
- Convert between CIDR and netmask.

## Concepts practiced
- IP addressing
- Subnetting
- Input validation

## Libraries
- ipaddress

## Stretch goals
- Split a network into N equal subnets.
- Group a list of IPs by subnet.
