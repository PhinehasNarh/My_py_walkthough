# 07. File Metadata Scrubber

## Problem
Strip hidden metadata (EXIF, author, GPS) from files before you share them.

## What you will build
- Read metadata from images and PDFs.
- Show what personal data is embedded.
- Write clean copies with the metadata removed.
- Never overwrite the originals.

## Concepts practiced
- File metadata
- Privacy
- Safe writes

## Libraries
- Pillow
- pypdf

## Stretch goals
- Batch-scrub a whole folder.
- Report exactly what was removed from each file.

## Authorized use
Run this only against systems, accounts, or data you own or have explicit written permission to test. This is for learning and defensive use.
