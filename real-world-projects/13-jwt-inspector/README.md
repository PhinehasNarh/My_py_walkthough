# 13. JWT Inspector & Weakness Checker

## Problem
Understand and test JSON Web Tokens used by web apps you are allowed to test.

## What you will build
- Decode the header and payload of a token.
- Show claims and expiry in readable form.
- Test for the 'none' algorithm weakness.
- Try a small wordlist against a weak HMAC secret.

## Concepts practiced
- JWT structure
- Base64
- Algorithm confusion

## Libraries
- pyjwt
- hashlib

## Stretch goals
- Forge a token once a weak secret is found (lab only).
- Add RS256 vs HS256 checks.

## Authorized use
Run this only against systems, accounts, or data you own or have explicit written permission to test. This is for learning and defensive use.
