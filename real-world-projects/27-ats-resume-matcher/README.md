# 27. Resume vs Job-Description ATS Matcher

## Problem
See how well your resume matches a job description before you apply.

## What you will build
- Read your resume and a job description.
- Extract keywords and skills from both.
- Compute overlap and list missing terms.
- Give a match score and suggestions.

## Concepts practiced
- Text processing
- Keyword extraction
- Scoring

## Libraries
- re
- collections

## Stretch goals
- Read resumes straight from PDF.
- Rank several job posts by fit.
