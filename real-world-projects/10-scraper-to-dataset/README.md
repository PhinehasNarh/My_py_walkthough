# 10. Web Scraper to Dataset

## Problem
Turn a website's listings into a clean, deduplicated dataset you can analyze.

## What you will build
- Fetch and parse listing pages.
- Extract structured fields into records.
- Deduplicate and append only new items.
- Save to CSV or SQLite with a timestamp.

## Concepts practiced
- HTML parsing
- Pagination
- Deduplication
- Polite scraping

## Libraries
- requests
- beautifulsoup4

## Stretch goals
- Schedule it and track changes over time.
- Add filters and a simple search over the dataset.
