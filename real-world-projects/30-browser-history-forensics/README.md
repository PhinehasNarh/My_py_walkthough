# 30. Browser History Forensics

## Problem
Reconstruct browsing activity from a browser's own database, on a machine you own.

## What you will build
- Locate and copy the browser history SQLite file.
- Query visited URLs, titles, and timestamps.
- Build a timeline of activity.
- Search and filter by date or keyword.

## Concepts practiced
- SQLite
- Timestamps
- Digital forensics basics

## Libraries
- sqlite3
- datetime

## Stretch goals
- Add downloads and search terms.
- Export a timeline report.
