# 03. Bulk File Renamer

## Problem
Rename a whole folder of files consistently instead of one by one.

## What you will build
- Take a folder and a rename rule (pattern or regex).
- Preview every planned rename first (dry run).
- Apply only after confirmation, avoiding name clashes.
- Write an undo file that can reverse the run.

## Concepts practiced
- Filesystem paths
- Regular expressions
- Dry-run safety

## Libraries
- pathlib
- re

## Stretch goals
- Support sequence numbers and date prefixes.
- Add EXIF-date renaming for photos.
