# 24. Steganography Tool

## Problem
Learn how data can be hidden inside images by building hide and extract tools.

## What you will build
- Encode a message into the least significant bits of a PNG.
- Save the carrier image with the hidden data.
- Extract the message back out.
- Add an optional passphrase.

## Concepts practiced
- Bit manipulation
- Image pixels
- Encoding

## Libraries
- Pillow

## Stretch goals
- Encrypt the message before hiding it.
- Detect whether an image likely carries hidden data.
