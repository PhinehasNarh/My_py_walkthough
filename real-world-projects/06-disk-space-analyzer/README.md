# 06. Disk Space Analyzer

## Problem
See what is actually eating your disk space instead of guessing.

## What you will build
- Recursively measure folder sizes from a starting path.
- Sort and show the biggest folders and files.
- Render a simple size tree.
- Let the user drill into a subfolder.

## Concepts practiced
- Recursion
- Filesystem stats
- Sorting and formatting

## Libraries
- pathlib
- os

## Stretch goals
- Export the report to CSV.
- Add a bar-style visual of relative sizes.
