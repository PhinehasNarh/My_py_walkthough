# 21. Typosquatting Domain Checker

## Problem
Find lookalike domains that could be used to impersonate a brand.

## What you will build
- Generate typo variations of a domain (swaps, omissions, homoglyphs).
- Check which variants actually resolve.
- Pull WHOIS age and records for the live ones.
- Flag the suspicious registrations.

## Concepts practiced
- String permutations
- DNS
- Brand protection

## Libraries
- dnspython
- python-whois

## Stretch goals
- Compare TLS certificates against the real site.
- Score each lookalike by risk.
