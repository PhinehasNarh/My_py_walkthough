# 09. Website Change Monitor

## Problem
Get told when a web page changes instead of refreshing it yourself.

## What you will build
- Fetch a page and store a snapshot.
- On the next run, fetch again and diff against the snapshot.
- Report exactly what changed.
- Run on a schedule.

## Concepts practiced
- HTTP requests
- Diffing
- Scheduling

## Libraries
- requests
- difflib
- schedule

## Stretch goals
- Watch only a CSS-selected part of the page.
- Send an alert when a change is detected.
