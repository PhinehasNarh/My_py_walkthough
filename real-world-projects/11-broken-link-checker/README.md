# 11. Broken Link Checker

## Problem
Find dead links on a website before your visitors do.

## What you will build
- Crawl a site starting from one URL.
- Collect internal and external links.
- Request each link and record its status.
- Report broken links and where they were found.

## Concepts practiced
- Crawling
- HTTP status codes
- Avoiding loops

## Libraries
- requests
- beautifulsoup4

## Stretch goals
- Limit crawl depth and respect robots.txt.
- Output an HTML report.
