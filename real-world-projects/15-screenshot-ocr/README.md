# 15. Screenshot OCR Tool

## Problem
Pull text out of screenshots and images instead of retyping it.

## What you will build
- Take an image file or a clipboard image.
- Run OCR to extract the text.
- Clean up the output.
- Copy the result to the clipboard or a file.

## Concepts practiced
- OCR
- Image handling
- Clipboard

## Libraries
- pytesseract
- Pillow
- pyperclip

## Stretch goals
- Batch-OCR a folder of images.
- Preserve simple layout in the output.
