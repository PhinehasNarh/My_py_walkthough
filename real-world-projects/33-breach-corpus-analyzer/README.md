# 33. Wordlist / Breach Corpus Analyzer

## Problem
Understand how people actually pick passwords by analyzing a public breach wordlist.

## What you will build
- Stream a large wordlist efficiently.
- Compute length, character-class, and pattern statistics.
- Find the most common passwords and structures.
- Output a report with tables or charts.

## Concepts practiced
- Streaming large files
- Statistics
- Pattern analysis

## Libraries
- collections
- matplotlib

## Stretch goals
- Recommend a password policy from the data.
- Estimate how many passwords would beat a given policy.
