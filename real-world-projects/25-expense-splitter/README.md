# 25. Expense Splitter

## Problem
Work out who owes whom after a group shares costs.

## What you will build
- Record who paid for what and who shared it.
- Compute each person's net balance.
- Produce the smallest set of settle-up payments.
- Save and reload a group's history.

## Concepts practiced
- Data modelling
- Greedy settlement algorithm
- Persistence

## Libraries
- json

## Stretch goals
- Support multiple currencies.
- Add a per-person report.
