# 23. TLS / Cipher Suite Scanner

## Problem
See which TLS versions and ciphers a server accepts, on hosts you are allowed to test.

## What you will build
- Connect to a host and port over TLS.
- Probe which protocol versions are accepted.
- Probe which cipher suites negotiate.
- Flag weak or outdated options.

## Concepts practiced
- TLS handshakes
- Sockets
- Security baselines

## Libraries

- socket
