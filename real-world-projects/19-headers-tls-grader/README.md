# 19. HTTP Security Headers + TLS Grader

## Problem
Grade how well a site is configured for transport and header security.

## What you will build
- Request a URL and read its headers.
- Check for the recommended security headers.
- Inspect the TLS certificate and expiry.
- Produce a letter grade with reasons.

## Concepts practiced
- HTTP headers
- TLS basics
- Scoring

## Libraries
- requests
- ssl
- socket

## Stretch goals
- Grade a list of sites from a file.
- Explain the risk of each missing control.
