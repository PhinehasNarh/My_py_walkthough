# 31. YARA Malware Triage Scanner

## Problem
Triage suspicious files by scanning them against pattern-based detection rules.

## What you will build
- Load YARA rules from a rules folder.
- Scan a single file or a directory of samples.
- Report which rules matched and where.
- Write your own rule to catch a known sample.

## Concepts practiced
- Pattern matching
- Detection rules
- Malware triage

## Libraries
- yara-python

## Stretch goals
- Pull and organize community rule sets.
- Output a triage report with severities.

- [ ] Not started

## Authorized use
Run this only against systems, accounts, or data you own or have explicit written permission to test. This is for learning and defensive use.
