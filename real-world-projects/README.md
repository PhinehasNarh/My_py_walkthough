# Python Real-World Projects

A hands-on project series that continues my Python journey from fundamentals into
real, useful tools. Each project solves an actual problem and adds new skills.
The set mixes everyday utilities with security and networking work, since that is
the direction I am heading.

## How this is organized

- Projects are numbered 01 to 35 in roughly increasing difficulty.
- Each lives in its own folder with a `README.md` (the brief) and a `main.py` (where the code goes).
- [ACTION-ITEMS.md](ACTION-ITEMS.md) is the working board: the full shortlist with checkboxes.

## The four tiers

1. Tier 1: approachable but genuinely useful command-line tools.
2. Tier 2: files, parsing, and real API work.
3. Tier 3: networking, databases, and security tooling.
4. Tier 4: apps, forensics, and larger builds.

## How I work through them

- One project per week, in order, though I am free to jump ahead when something grabs me.
- Build the code in that project's `main.py`, run it until it works, then tick the box in ACTION-ITEMS.md and commit.
- Use a virtual environment and add a `requirements.txt` per project once it needs third-party libraries.

## A note on the security projects

Projects tagged with security are for learning and defensive use. Anything that
touches a network, an account, or a target is run only against systems I own or have
explicit permission to test.

Total projects: 35.
