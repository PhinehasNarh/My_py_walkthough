# 08. Smart Downloads Organizer

## Problem
Keep a messy Downloads folder tidy automatically by type and rules.

## What you will build
- Scan a folder for files.
- Sort into category folders using configurable rules.
- Move files safely without clobbering.
- Add a watch mode that organizes new arrivals.

## Concepts practiced
- Filesystem walking
- Rule engines
- Watching for changes

## Libraries
- pathlib
- shutil
- watchdog

## Stretch goals
- Load rules from a JSON config.
- Auto-unzip archives into named folders.
