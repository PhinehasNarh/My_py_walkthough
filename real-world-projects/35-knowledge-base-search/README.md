# 35. Personal Knowledge Base / Note Search CLI

## Problem
Make all your scattered notes instantly searchable from the terminal.

## What you will build
- Index a folder of markdown or text notes.
- Support full-text search with ranking.
- Filter by tags and dates.
- Open the chosen note from the results.

## Concepts practiced
- Indexing
- Search ranking
- Tagging

## Libraries
- whoosh
- pathlib

## Stretch goals
- Add fuzzy search.
- Show snippets with the matched terms highlighted.
