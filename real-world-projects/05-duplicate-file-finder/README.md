# 05. Duplicate File Finder

## Problem
Reclaim disk space by finding exact duplicate files across folders.

## What you will build
- Walk one or more folders.
- Group files by size, then confirm duplicates with a content hash.
- List duplicate sets and the space they waste.
- Offer to delete or link the extras, with confirmation.

## Concepts practiced
- Hashing
- Filesystem walking
- Efficient comparison

## Libraries
- hashlib
- pathlib

## Stretch goals
- Add a quick mode that hashes only part of large files.
- Keep the newest copy automatically.
