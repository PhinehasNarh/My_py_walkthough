# 14. Spaced-Repetition Flashcards

## Problem
Study and retain material efficiently with a real spaced-repetition algorithm.

## What you will build
- Store cards (question, answer) in a file.
- Schedule reviews with the SM-2 algorithm.
- Run a review session and grade recall.
- Update each card's interval based on your grade.

## Concepts practiced
- Algorithms (SM-2)
- Scheduling
- Persistence

## Libraries
- json
- datetime

## Stretch goals
- Import decks from CSV.
- Show study stats and a streak.
